5. Known caveats — not bugs

Render free-tier cold start (~30s): First API call after 15+ minutes of inactivity. Subsequent calls are instant.
Uploaded photos may disappear after redeploy: Render free tier has ephemeral filesystem. Selfies + bill photos uploaded to /api/uploads are wiped on every backend redeploy. For real production, swap to S3.
Sync interval is 15 min: Pending items don't push instantly. Force a sync by quitting + reopening the app (it triggers WorkManager). For testers needing immediate sync, this is the workaround.
Tour plan creation from mobile: Not yet implemented (Phase 3.1). Tour plans only show — they're created from admin or via direct API.
Database wipe on schema change: Room v3 with destructive migration — if app is updated with schema changes, local data resets.
JWT expiry — 30 days: Token expires → user is signed out → must log in again. Currently no refresh token.
